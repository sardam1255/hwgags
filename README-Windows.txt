===============================================================
  سیستەمی بەڕێوەبردنی قیست و سەرمایە (QISTYAR) - وەشانی ویندۆز
===============================================================

چۆنیەتی کارپێکردن لەسەر لاپتۆپ و کۆمپیوتەری ویندۆز (Windows):

ڕێگای یەکەم (خێراترین و ئاسانترین - ئەگەر فایلی EXEـت داگرتووە):
١. تەواوی فۆڵدەرەکە لە فایلی ZIP دەربهێنە (Extract All).
٢. ڕاستەوخۆ دووجار کلیک لەسەر فایلی (QISTYAR.exe) یان (Start-QISTYAR.bat) بکە.
٣. بە شێوەیەکی ئۆتۆماتیکی سیستەمەکە دەکرێتەوە و لەسەر وێبگەڕەکەت لاپەڕەی سیستەمەکە پێشاندەدرێت (http://localhost:3000).
٤. هەموو گرێبەست، وەسڵ و داتاکانت لەناو فۆڵدەری (data/db.json) لەسەر لاپتۆپەکەت بە پارێزراوی خەزن دەبن و پێویستت بە هیچ ئینتەرنێتێک نییە!

ڕێگای دووەم (ئەگەر کۆدی پڕۆژەکەت داگرتووە):
١. دڵنیابە بەرنامەی Node.js لەسەر لاپتۆپەکەت دابەزیوە لە: https://nodejs.org
٢. دووجار کلیک لەسەر (Start-QISTYAR.bat) بکە.
٣. بۆ یەکەمجار پێداویستییەکان دادەمەزرێنێت و ڕاستەوخۆ دەستپێدەکات.
